REGISTRY OF THE ORDER

공개 열람분 — 사후(死後) 해제 인사에 한함

회칙 제3율에 따라 단원의 이름은 생전에 공개되지 않는다. 아래 명부는 사후 100년 경과 또는 평의회 의결로 봉인 해제된 인사에 한한다. 생존 단원 명부는 ACCESS Ⅱ 이상의 열람 사항이다.

Ante Ordinem · 결사 이전

THE PRECURSORS

선구자 — 회는 이들을 소급하여 명부에 올렸다
Retroactive
FILE № 0000-A · CODENAME: LUX
히파티아 Hypatia
c.360 – 415 · Alexandria
알렉산드리아의 마지막 수학 강사. 원뿔곡선 주해로 군중이 이해하지 못하는 것을 가르쳤고, 군중은 이해하지 못하는 자를 살해했다. 회의 제1율 — "회에 대해 묻는 자에게, 회는 없다" — 는 그녀의 죽음에서 나왔다. 드러난 지성은 표적이 된다.
Retroactive
FILE № 0000-B · CODENAME: RADIX
알콰리즈미 al-Khwārizmī
c.780 – 850 · Baghdad · House of Wisdom
회의 이름이 그의 책에서 왔다 — al-jabr(복원), 곧 algebra. 부서진 것을 항을 옮겨 복원하는 기술. 회가 하는 일의 정의이기도 하다. '알고리즘'이라는 단어 또한 그의 이름의 와전이니, 우리는 그의 이름 안에서 산다.
Retroactive
FILE № 0000-C · CODENAME: SIGNUM
피보나치 Leonardo of Pisa
c.1170 – 1250 · Pisa
인도-아라비아 숫자를 유럽에 밀수한 상인의 아들. 로마 숫자로 셈하던 대륙의 연산 속도를 한 세기 만에 바꿨다. 회는 이를 최초의 '조용한 개입' 사례로 분류한다 — 칼 없이, 표기법 하나로.
Fundatores et Archivum

FOUNDERS & ARCHIVED MEMBERS

창립자와 봉인 해제 단원
Founder
FILE № 1637-01 · CODENAME: CORVUS PRIMUS
르네 데카르트 René Descartes
1596 – 1650 · La Flèche → Stockholm
초대 원점(Origo). 1637년, 인쇄되지 않은 여덟 페이지로 회를 결성했다. 공개 사인(死因)은 폐렴. 흑서고의 기록은 다르지만, 해당 항목은 ACCESS Ⅲ 열람 사항이다. 그의 서명 대신 남은 것은 두 개의 직교하는 선뿐이다.
Archived
FILE № 1687-04 · CODENAME: POMUM
아이작 뉴턴 Isaac Newton
1642 – 1727 · Cambridge · Council Seat Ⅱ
제2대 평의회 의석 Ⅱ. 『프린키피아』의 3할을 스스로 검열한 장본인. 조폐국장 시절 위조범을 추적한 것은 부업이 아니라 회의 소거 임무였다. 사과 일화는 본인이 승인한 위장 서사다 — 대중은 신화를 원하고, 회는 대중이 신화에 만족하기를 원한다.
Archived
FILE № 1736-02 · CODENAME: PONS
레온하르트 오일러 Leonhard Euler
1707 – 1783 · Basel → St. Petersburg
쾨니히스베르크의 일곱 다리 문제를 풀며 그래프 이론을 열었다 — 회에게는 연결망 감시 이론의 탄생이었다. 실명 후에도 구술로 800편을 남겼다. 침묵의 근육과 기록의 규율, 두 소양의 교본으로 승급 교육에 쓰인다.
Archived
FILE № 1801-07 · CODENAME: PRINCEPS
카를 프리드리히 가우스 C. F. Gauss
1777 – 1855 · Göttingen · Council Seat Ⅴ
소행성 세레스의 궤도를 관측 데이터 몇 점으로 재발견해 유럽을 놀라게 했다 — 회의 관측 부서가 그를 주시한 계기다. 완성되지 않은 결과를 발표하지 않는 결벽(pauca sed matura, 적게 그러나 무르익게)은 회칙 제3율의 모범 사례로 인용된다.
Lost
FILE № 1832-00 · CODENAME: — 미부여 —
에바리스트 갈루아 Évariste Galois
1811 – 1832 · Paris · 영입 실패
명부에서 유일하게 코드네임이 없는 이름. 검은 봉투는 결투 다음 날 아침 그의 하숙집에 도착했다. 회가 늦은 유일한 기록. 이후 관측 지침 제1원칙("늦기 전에")이 제정되었고, 매년 5월 30일 흑서고는 그의 미공개 60페이지를 하루 동안 전 단원에게 개방한다.
Archived
FILE № 1843-12 · CODENAME: MACHINA
에이다 러브레이스 Ada Lovelace
1815 – 1852 · London
존재하지 않는 기계를 위한 프로그램을 썼다 — 회는 이를 실물 없이 함수를 신뢰하는 능력의 최초 사례로 분류한다. 그녀의 주석 G는 흑서고 사본이 공개본보다 11페이지 길다.
Archived
FILE № 1854-01 · CODENAME: DUO
조지 불 George Boole
1815 – 1864 · Cork · Council Seat Ⅶ
독학자. 사고(思考)를 0과 1의 대수로 환원했고, 회는 즉시 전 암구호 체계를 그의 언어로 개정했다. 오늘날 최상위 열람 권한이 2진으로만 발급되는 전통이 그에게서 왔다. 까마귀의 언어의 아버지.
Archived
FILE № 1915-03 · CODENAME: SYMMETRIA
에미 뇌터 Emmy Noether
1882 – 1935 · Göttingen → Bryn Mawr
대칭이 있는 곳에 보존량이 있다 — 뇌터 정리는 회의 감시 이론 전체를 다시 쓰게 했다. 변하지 않는 것을 찾으면 숨은 대칭이 보인다는 그녀의 원리는 현재도 자금 흐름 관측 부서의 제1도구다. 무급 강사 시절에도 강의를 멈추지 않은 이력은 소양 제8항(숫자에 대한 예의)의 예화로 쓰인다.
Archived
FILE № 1913-09 · CODENAME: SOMNIUM
스리니바사 라마누잔 S. Ramanujan
1887 – 1920 · Madras → Cambridge
증명 없이 참을 꺼내는 능력 — 회의 분류 체계로는 설명 불가능한 유일한 파일. 그의 노트 중 '잃어버린 노트'가 1976년에야 발견된 것은 우연이 아니다. 회가 반납한 것이다. 세상이 받아들일 준비가 되는 속도에 맞춰서.
Archived
FILE № 1936-06 · CODENAME: ORACULUM
앨런 튜링 Alan Turing
1912 – 1954 · Bletchley Park · 개입 제1호
회칙 제2율("관측하되 개입하지 말라")이 389년 역사상 유일하게 정지된 작전의 중심. 블레츨리 파크 투입 인원 중 회의 단원 수는 아직도 ACCESS Ⅲ 사항이다. 회가 그를 지키지 못한 1954년은, 갈루아 이후 두 번째의 공식 애도일로 지정되어 있다.
Archived
FILE № 1945-11 · CODENAME: IANUS
존 폰 노이만 John von Neumann
1903 – 1957 · Budapest → Princeton
게임이론, 컴퓨터 구조, 그리고 차마 명부에 적지 못하는 것들. 두 얼굴의 야누스라는 코드네임은 그가 회에서 맡은 역할 때문이다 — 표면의 자문가이자, 심층의 계산가. 그의 병상 곁을 군이 지킨 이유를 공개 사학은 아직 절반만 안다.
Active
FILE № 20██-██ · CODENAME: ████████
██████ ██████
19██ – · ██████
생존 단원의 기록은 회칙 제3율에 따라 표시할 수 없다. 이 카드가 비어 있는 것이 아니다 — 당신의 열람 등급이 낮은 것이다. ACCESS Ⅱ 이상은 터미널에서 열람하라.
